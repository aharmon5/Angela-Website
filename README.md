# Angela Harmon - Producer & Media Visionary

Professional portfolio website featuring water animation effects and responsive design.

## Deployment to GitHub Pages

This repository is ready to be deployed to GitHub Pages for free hosting.

### Quick Setup Instructions:

1. **Create a new repository on GitHub:**
   - Go to https://github.com/new
   - Name it (e.g., `angela-harmon-portfolio` or `my-website`)
   - Make it **Public** (required for free GitHub Pages)
   - Do NOT initialize with README, .gitignore, or license

2. **Push this code to GitHub:**
   ```bash
   git add .
   git commit -m "Initial commit - Portfolio website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - Go to your repository on GitHub
   - Click **Settings** tab
   - Scroll down to **Pages** section
   - Under "Source", select **main** branch
   - Click **Save**
   - Wait 1-2 minutes for deployment

4. **Your website will be live at:**
   ```
   https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/
   ```
